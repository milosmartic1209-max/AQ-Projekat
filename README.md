# AQ Sajt

Profesionalni web sajt za AQ Accounting, knjigovodstvenu i konsultantsku firmu iz Crne Gore.

## Struktura projekta

- `public/` - Sadrži `index.html` i slike
- `src/` - Sadrži CSS, JavaScript i dodatne stranice
   - `css/styles.css` - Glavni stilovi
   - `js/script.js` - Interakcije i animacije
   - `pages/` - Sekundarne stranice (`about-us.html`, `service-listing.html`)

## Ključne funkcionalnosti
- Mobilno prilagođen dizajn (CSS Grid, Flexbox)
- Animacije pri skrolovanju
- Validacija kontakt forme
- Lokalizovan sadržaj za Crnu Goru
- Timeline animacija poslovnog puta
